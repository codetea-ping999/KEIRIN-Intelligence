# 競輪予想AI ロードマップ（やさしい日本語版）

KEIRIN Intelligence で「何を・どの順番で・誰が」やるのかを、プログラムを知らない人向けにまとめました。
英語の README や設計書の中身を、日本語でかみくだいたものです。

---

## 1. ひとことで言うと

> **かんたさんの競輪の読み（ノウハウ）を「数字のルール」に置きかえて、AIに覚えさせる。**
> **その予想が本当に当たるかを、ごまかしなしで記録してから、noteで販売する。**

AIは魔法ではありません。AIができるのは、
「過去のレースで、どんな条件の選手がよく勝ったか」を大量のデータから見つけて、確率で出すことだけです。
だから、**何を見れば当たるのか**を知っている人（かんたさん）の知識がいちばん大事です。

---

## 2. 全体の流れ（5ステップ）

```
① 出走表を入力 → ② AIが確率を計算 → ③ 締切前に予想を記録（あとで書きかえ不可）
      → ④ レース後に結果を入力 → ⑤ 当たり外れを集計して、AIを賢くする
                                       ↓
                         十分に当たると確認できたら note で販売
```

| ステップ | やること | 担当の目安 |
|---|---|---|
| ① 入力 | 公式の出走表を見て、得点・脚質・並び（ライン）などを表に入力 | かんた / おてぃよ |
| ② 計算 | `keirin predict` で各選手の1着率・3着内率を出す | AI（自動） |
| ③ 記録 | `keirin freeze` で締切前に予想を固定。改ざんできない形で保存 | おてぃよ |
| ④ 結果 | レース後に着順を入力 | かんた / おてぃよ |
| ⑤ 検証 | `keirin evaluate` で「得点だけの予想」より当たっているかを確認 | AI＋2人で確認 |

---

## 3. かんたさんのノウハウを AI に落とし込む方法

ここがいちばん大事なところです。かんたさんが普段レースを見るときに考えていることを、
**「AIが読める項目（数字や○×）」**に分けていきます。

### やり方

1. **いつも見ているポイントを書き出す**
   例：「地元の選手は強い」「番手の選手が一番おいしい」「500バンクは追い込みが届く」「雨の日は先行有利」
2. **それを、表の1列（項目）にできるか考える**

| かんたさんの読み（例） | AIが読める形にすると | いまのAIにあるか |
|---|---|---|
| 競走得点が高い選手は強い | 得点（数字） | ✅ あり |
| 強いラインの番手が有利 | ライン内の位置（先頭/番手/3番手/単騎） | ✅ あり |
| ラインで決まりやすい（1-2着がライン） | 「前の選手に続いてゴール」効果 | ✅ あり |
| 逃げ選手かどうか | 脚質（逃/両/追） | ✅ あり |
| 地元の選手は気合いが入る | 地元かどうか（○×） | ⬜ これから追加 |
| バンクの長さ・直線で有利不利が変わる | 周長（333/400/500）、直線の長さ | ⬜ これから追加 |
| 最近の調子 | 直近4か月の着順・勝率 | ⬜ これから追加 |
| 天気・風 | 雨か、風速 | ⬜ これから追加 |

3. **AIが「その読みは本当に効くのか」を数字で判定する**
   データが貯まると、AIは「地元の効果はこれくらい」「番手の効果はこれくらい」と重みを自動で調整します。
   かんたさんの読みが正しければ重みが大きくなり、思い込みだったら小さくなります。
   **これで、かんたさんの勘が本当に当たっているかも分かります。**

### Museの資料について

Museで共有してもらった資料は、AI側からは開けませんでした（Museが外部からの自動読み取りを止めているため）。
資料に書いた「予想の考え方」を、**md・pdf・テキスト**のどれかで渡してもらえれば、上の表に1つずつ追加していきます。
画像やメモでも、書いてある内容を文字にしてもらえれば大丈夫です。

---

## 4. データについての約束

- 公式サイト（KEIRIN.JP）は、プログラムでの自動取得を禁止しています。
  なので**出走表は人が見て手で入力**します。1レース7〜9行なので、慣れれば数分です。
- 入力するのは、得点・脚質・並びなどの**事実の情報だけ**。
  他のサイトの予想印や記者コメントはコピーしません（他人の著作物になるため）。
- たくさんの過去データを一気に使いたくなったら、JKA などのデータ提供元に正式に相談します。

## 5. 「高精度」と言えるまでの道のり

| 段階 | 目安 | note でできること |
|---|---|---|
| A. 準備 | いま | 無料記事で「分析の考え方」を紹介 |
| B. 記録 | 数百レース、8〜12週間 | 締切前に固定した予想の成績を、外れも含めて公開 |
| C. 確認 | AIが「得点だけの予想」を安定して上回る | 有料記事・メンバーシップを検討 |
| D. 販売 | 規約・表示ルールを確認したあと | 有料販売スタート |

**大事なルール**
- 「必ず当たる」「絶対」「確実に儲かる」は書かない（法律や note のルールに触れるおそれ）。
- 成績を書くときは、**事前に記録した全レースの数字**（外れも含む）だけを使う。
- 「エンタメ目的」「的中保証なし」「20歳以上」の注意書きは必ず入れる。

---

## 6. パソコン（Mac Studio）について

いまのAI（M1モデル）は軽いので、**普通のノートパソコンで十分に動きます**。
数万レース分のデータで大きなモデル（LightGBMなど）を学習させる段階になってから、
高性能なマシンを検討すれば間に合います。先にデータを貯めることのほうが大切です。

---

## 7. 次にやること

1. **かんた**：普段の予想で見ているポイントを、思いつくだけ箇条書きにする（md / pdf / テキストで共有）
2. **おてぃよ**：その中から「地元」「バンク」「近況」など、入力できる項目をAIに追加する
3. **2人で**：毎日数レースずつ入力 → 締切前に固定 → 結果入力、を続けて成績を貯める
