# 解説文の自動生成に Sarashina を使えるか（検証メモ）

`scripts/sarashina_check.py` は、架空のサンプルレースだけを Sarashina に送り、展開解説の質と安全性を確かめるスクリプトです。
APIキーは環境変数 `SARASHINA_API_KEY` からだけ読みます（コード・ファイル・コミットには入れません）。

```bash
export SARASHINA_API_KEY=...      # chat.sarashina.ai のダッシュボードで発行したキー
python scripts/sarashina_check.py --model sarashina3-nano
```

返ってきた文章は、保証・断定表現（`note.BANNED_PHRASES`）と、入力にない数値が混ざっていないかを自動でチェックします。

## 無料版の条件（公開情報の要点。利用前に最新の規約で再確認すること）

- エンドポイント `https://api.sarashina.ai/v1/chat/completions`、`max_tokens` ではなく `max_completion_tokens`。
- 無料枠は mini / guard / translate が毎分6回、nano / embedding / rerank が毎分60回。超えると429（Retry-After なし）。
- 入力と出力はモデル学習に使われうる（オプトアウトは有料プランのみ）。個人情報は入力禁止。
- 医療・法律・金融の助言としての利用は禁止。競合サービスを作る目的での出力利用も禁止。
- 出力のプログラムによる自動抽出は制限される可能性があり、大量処理の前に提供元へ確認が必要。
- 無料ベータは日本国内の個人・法人向けで、終了時期は未定。

## このプロジェクトでの使い方の方針

1. 送るのは**出走表の事実情報と推定確率だけ**（選手名は公表されている競技者名のみ。私的な情報は送らない）。
2. 出力は**下書きの一部**として使い、人が読んで直してから公開する。自動投稿はしない。
3. 買い目の推奨や的中の示唆を書かせない（システムプロンプトと自動チェックで抑止）。
4. **有料noteの制作に使ってよいかは、規約の「商用利用」「出力の利用範囲」を提供元に確認してから**。確認前は検証用途に限る。
