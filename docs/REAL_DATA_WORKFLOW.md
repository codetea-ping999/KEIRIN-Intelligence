# 実選手データでの運用手順（v0.2）

実在選手の出走表を**人が手入力**し、予想・事前固定・結果入力・検証・note下書きまでを回す手順です。
このコードはデータの自動取得、車券購入、noteへの自動投稿を一切行いません。

## 1. データの入手方針

| 入手経路 | 現状 | 使い方 |
|---|---|---|
| KEIRIN.JP（JKA公式） | robots.txt で自動アクセス不可 | ブラウザで閲覧し、必要な項目だけ手入力する。スクレイピングしない |
| 民間サイト（netkeirin、オッズパーク、WINTICKET、チャリロト等） | 各社の利用規約が自動取得・転載を制限している可能性が高い | 規約を確認するまで自動取得しない。印・記者予想・コメントは各社の著作物なので転載しない |
| JKA等とのデータ提供契約 | 未着手 | 過去データを大量に使った学習や有料販売を本格化する場合の本命。`docs/DATA_LICENSING.md` のチェックリストで確認する |

手入力するのは、車番・選手名・級班・府県・競走得点・脚質・並び（ライン）といった**事実情報**だけにします。
他社の予想印、記者コメント、画像は入力・転載しません。有料販売前には、提供元への確認または専門家への相談を推奨します（法的助言ではありません）。

## 2. フォルダ構成

`data/real/`（git管理外）に以下の CSV を置きます。書式は `data/templates/` を参照。

- `races.csv` — 1レース1行。`venue` は競輪場名（`data/reference/velodromes.csv` の表記、例: 立川）。`betting_cutoff_at` / `observed_at`（出走表を見た時刻）/ `entered_at`（入力した時刻）は `+09:00` 付きで記入。任意列: `back_wind_mps`（バック向かい風を＋、追い風を−で m/s）、`wet`（路面が濡れていれば1、乾いていれば0）。
- `entries.csv` — 1選手1行。`style` は `逃` / `両` / `追`。`line_group` は同じラインに同じ番号、`line_pos` は先頭=1, 番手=2…。単騎は1人だけのグループ。
- `results.csv` — 結果。`finish` に着順、失格・落車などは空欄。
- `ledger.jsonl` — 事前固定した予想の記録（自動生成。手で編集すると改ざん検知で止まります）。
- `weights.json` — `keirin fit` で学習した重み（無ければ事前設定値を使用）。

## 3. 1レースの流れ

```bash
pip install -e .
keirin --data data/real predict 20261103-TACHIKAWA-11   # 確率を確認
keirin --data data/real freeze  20261103-TACHIKAWA-11   # 締切前に予想を固定（ハッシュ記録）
keirin --data data/real note    20261103-TACHIKAWA-11 --out drafts/20261103-11.md
# → 下書きを人が読み、docs/NOTE_PUBLISHING.md のチェック後に手動でnoteへ投稿
# レース後: results.csv に着順を追記
```

`freeze` は締切後には実行できず、同じレースを二度固定することもできません。
note の「これまでの記録」は ledger に固定した予想だけから外れも含めて集計されます。

## 4. 精度を上げる・確かめる

モデル（M1）は「競走得点」「ラインの強さ」「先頭/番手/3番手/単騎」「逃げ脚質」と、
**同じラインの前の選手に続いてゴールしやすい**効果（ライン連携）を持つ逐次ロジットです。
初期値は競輪の一般的な傾向に基づく仮置きで、実データでの精度はまだ分かりません。

```bash
keirin --data data/real evaluate --min-train 100   # 月単位のウォークフォワード検証
keirin --data data/real fit --before 2026-12-01     # 指定日より前の結果で重みを学習
```

`evaluate` は M1（毎月その前月までのデータで再学習）、M1初期値、得点のみ、一様ランダムの4つを
同じレースで比較し、1着の対数損失・Brier・本命1着率・本命3着内率・2車単1点・3連単上位6点の的中率を出します。

**目安**: 少なくとも数百レース・8〜12週間分の結果と事前固定記録が貯まるまでは、
「高精度」「的中率◯%」といった表現は使いません。M1が「得点のみ」を安定して上回ることが、精度向上の最初の証拠になります。
