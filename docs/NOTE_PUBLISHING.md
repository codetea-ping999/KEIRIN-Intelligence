# note 公開前チェックリスト

`keirin note` が作るのは**下書き**です。投稿は必ず人が確認してから手動で行います。

## 表現（景品表示法・消費者保護の観点）

- [ ] 「必ず当たる」「絶対」「確実に儲かる」「元本保証」「必勝」などの断定・保証表現がない（下書き生成時にも自動チェック）
- [ ] 的中率・回収率を書く場合は、ledger に事前固定した全レースの数字（外れ・対象期間・レース数を含む）である
- [ ] バックテスト（過去データでの検証）の数字を、実際に事前公開した成績のように書いていない
- [ ] 「エンタメ目的」「的中・利益の保証なし」「20歳以上」「相談窓口」の注意書きが残っている

## データと権利

- [ ] 出走表の事実情報のみを使い、他社の予想印・記者コメント・画像・ロゴを転載していない
- [ ] 選手を誹謗中傷する表現、私生活に関する記述がない
- [ ] 欠車・並び変更など、最新の公式発表を確認した

## 有料販売をする場合

- [ ] note の利用規約・ガイドライン（有料記事、公営競技コンテンツの扱い）を最新版で確認した
- [ ] 特定商取引法に基づく表記の要否を確認した
- [ ] データ利用の可否（`docs/DATA_LICENSING.md`）を確認し、記録した
- [ ] 収益の扱い（確定申告など）を把握している

このリストは法的助言ではありません。迷う点は専門家に確認してください。
