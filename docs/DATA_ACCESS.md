# データ取得の可否と許諾依頼（2026-11-06 時点）

依頼者から提示された4サイトについて、自動取得（クローリング／スクレイピング）をしてよいかを確認した結果です。
法的助言ではありません。最終判断は各サイト運営者への確認と専門家への相談で行ってください。

| サイト | 状態 | 根拠 |
|---|---|---|
| KEIRIN.JP（検索・資料室） | blocked | robots.txt が自動アクセスを拒否 |
| keirin.netkeiba.com | needs_permission | robots は全許可だが、利用規約 第14条（私的利用を超える複製・公開の禁止）、第15条（営利利用・その準備の禁止、別途承認がある場合を除く） |
| www.oddspark.com | unreviewed | robots.txt・利用規約をクラウド環境から読めず未確認 |
| gamboo.jp | unreviewed | 同上 |

正本は `data/reference/source_terms.csv` です。`src/keirin_intelligence/sources.py` の
`require_automation_allowed` は、状態が `permitted` で、かつ robots.txt が許可する場合のみ通します
（それ以外は `GateRejected`）。現状は `permitted` が0件なので、自動取得は何も動きません。

## 現在できること

- 公式の出走表を人が見て、事実情報（得点・脚質・並び・結果）を手入力する（`docs/REAL_DATA_WORKFLOW.md`）。
- 他サイトの予想印・記者コメント・文章は転載しない。

## 自動取得を始める条件

1. サイト運営者（JKA / KEIRIN.JP、netkeiba、oddspark、gamboo）から、**用途（note での有料配布を含む）を明記した書面の許諾**または公式データ提供を得る。
2. `source_terms.csv` の該当行を `permitted` に更新し、根拠（許諾日・条件）を記録する。
3. robots.txt と許諾の範囲内（頻度・項目）でのみ取得する。
