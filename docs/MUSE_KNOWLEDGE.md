# Muse 調査ボードから取り込んだ知見（2026-10-31）

共同開発者が共有した Muse の4つの調査ボード（2026-10-28〜29 調査、ユーザー生成・未検証）を読み、
予想モデルに使える項目だけを抜き出しました。ボード本文の転載はしていません（このリポジトリは公開です）。
**資料どうしで結論が割れる点は、重みを小さい事前値にして、実データで検証してから採用する**方針です。

| ボード | 内容 | 取り込み先 |
|---|---|---|
| Space 2 | バンクと天候の関係・全43場の周長／みなし直線／カント | `data/reference/velodromes.csv`、特徴量 `bank_*` `wind_*` `wet_nige` |
| Space 6 | 級班・男女で戦い方がどう違うか（決まり手の比率ほか） | 特徴量 `nige_lowclass`、7車立ての前提 |
| Space 3 | 現役選手まとめ（SS班・賞金など） | 選手個別データはレースごとの出走表から入力するため、今回は未使用 |
| 無題(Space) | 競輪の基礎知識、予想の基礎（出走表の読み方） | 出走表の入力項目の優先順位、注意書き |

## モデルに入れた項目と根拠

| 特徴量 | 意味 | 事前の向き | 根拠（資料の記述） |
|---|---|---|---|
| `bank_nige` | 逃げ選手 × (50 − みなし直線)/10 | 短い直線で逃げに有利 | みなし直線が短い（約45m未満）と先行が失速前にゴールしやすい |
| `bank_chaser` | 追い選手 × (みなし直線 − 50)/10 | 長い直線で追い込みに有利 | 長い（約60m超）と番手・追い込みが差せる |
| `wind_nige` / `wind_chaser` | バック向かい風(m/s ÷ 5) × 脚質 | 向かい風は逃げに不利、追いに有利 | 先行が消耗し後方が脚をためる。目安は5m/s超（経験則） |
| `wet_nige` | 路面が濡れている × 逃げ | 0（中立） | 「雨は堅い」「雨は荒れる」と資料が割れる |
| `local` | 選手の府県 = 開催場の府県 | 小さくプラス | 地元はバンク熟知・気合が材料になることがある（予想系） |
| `nige_lowclass` | A級の逃げ選手 | 小さくプラス | 逃げ1着の比率は A3 38.6% → A2 32.8% → S2 19.4% → S1 12.9% |

## 資料から分かった前提（実装で守っていること）

- 2020年10月以降、グレードレース以外は S級（FI）も含め最大7車立て。モデルは車立て数に依存しない。
- ライン内の1-2着（スジ決着）は S級 53.6%、A級1・2班 53.4%、チャレンジ 52.5% で級による差が小さい。
  → `follow`（前の選手に続く）項は級で分けず共通にしている。
- ガールズケイリンは先頭固定の個人戦でライン前提が違い、1着決まり手は捲りが約48〜49%。
  → **このモデルは男子のライン戦専用**。L級（ガールズ）の予想には使わない。
- 払戻率は約75%に設計されている。note の注意書きに反映済み。

## まだ入れていないもの（今後の候補）

- 選手の直近4か月の成績・決まり手の回数（出走表の列として追加が必要）
- 周長別（333 / 400 / 500）の効果。みなし直線で大部分を表せるか、データで確認してから
- カント（資料間で説が割れているため、単独では使わない）
- 気温・季節（確実に言えるのはタイムの季節性のみ）
