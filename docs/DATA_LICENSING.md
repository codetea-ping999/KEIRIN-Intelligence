# Commercial source approval checklist

**No data license has yet been approved in this repository.** All real-world inputs are blocked for commercial training and publication until legal and contractual review is recorded.

## Review for each provider

- Source owner, official contact, contract reference and fees.
- Allowed automated retrieval, API use, caching, storage and retention.
- ML training, derivative forecast sales on note, republishing and attribution.
- Limits on sharing and use after termination/revocation.
- Technical terms: rate limits, deletion requests and auditability.
- Document written approval or explicit denial for each operation.

Do not assume public visibility means a right to scrape or monetize. If licensing is unresolved, the commercial release gate remains **BLOCKED**.

**Important:** Current Python checks are starter guards only. Future ingestion, training and publication jobs must each enforce permissions at their boundary and retain audit evidence.
