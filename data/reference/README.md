# Reference data

`velodromes.csv` — 43 keirin venues: prefecture, lap length (m), "minashi" straight (m), cant (deg, decimal),
indoor flag. Compiled by the project collaborators from a research board dated 2026-10-28 that cites KEIRIN.JP's
venue data and Wikipedia「競輪場」. Venue figures are facts but sources disagree in places (cant especially);
re-check against KEIRIN.JP before relying on a single value. Chiba (250m, PIST6 only) has no straight/cant values.
